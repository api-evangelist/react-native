<h3 class="anchor anchorTargetStickyNavbar_tleR" id="new-animation-backend">New Animation Backend<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#new-animation-backend" title="Direct link to New Animation Backend">​</a></h3>
<p>React Native 0.85 introduces the new Shared Animation Backend, built in collaboration with <a class="" href="https://swmansion.com/" rel="noopener noreferrer" target="_blank">Software Mansion</a>.</p>
<p>This is a new internal engine that powers how animations are applied under the hood for both Animated and Reanimated. By moving the main animation update logic to React Native core, Reanimated is able to land performance improvements that weren't possible before, and can ensure that the update reconciliation process is properly tested and will remain stable with future RN updates.</p>
<p>In Animated, you can now animate layout props with native driver (the <a class="" href="https://reactnative.dev/docs/animations#caveats">limitation once stated here</a> no longer applies).</p>

<h3 class="anchor anchorTargetStickyNavbar_tleR" id="react-native-devtools-improvements">React Native DevTools Improvements<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#react-native-devtools-improvements" title="Direct link to React Native DevTools Improvements">​</a></h3>
<p>React Native DevTools received several improvements in this release:</p>
<ul>
<li class=""><strong>Multiple CDP connections</strong>: React Native now supports multiple simultaneous Chrome DevTools Protocol connections, enabling clients such as React Native DevTools, VS Code, and AI agents to connect at the same time. This unlocks richer, composable tooling workflows without unexpectedly ending sessions.</li>
<li class=""><strong>Native tabs on macOS</strong>: We've updated the desktop app to compile for macOS 26, and have also enabled system-level tab handling for power users. Access via <strong>Window &gt; Merge All Windows</strong>, when multiple DevTools windows are open.</li>
</ul>
<img alt="DevTools native tabs on macOS" src="https://reactnative.dev/blog/assets/0.85-devtools-macos-tabs.png" />
<ul>
<li class=""><strong>Request payload previews</strong>: After being disabled due to a regression, request body previews in the Network Panel are now restored on Android.</li>
</ul>

<h3 class="anchor anchorTargetStickyNavbar_tleR" id="jest-preset-moved-to-new-package">Jest Preset Moved to New Package<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#jest-preset-moved-to-new-package" title="Direct link to Jest Preset Moved to New Package">​</a></h3>

<h3 class="anchor anchorTargetStickyNavbar_tleR" id="dropped-support-for-eol-nodejs-versions">Dropped Support for EOL Node.js Versions<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#dropped-support-for-eol-nodejs-versions" title="Direct link to Dropped Support for EOL Node.js Versions">​</a></h3>
<p>React Native 0.85 drops support for end-of-life (EOL) Node.js versions and releases before v20.19.4. Please ensure you are running a supported version of Node.js before upgrading.</p>
<ul>
<li class=""><strong>Node.js v20</strong> (&gt;=20.19.4) — Supported (Active LTS)</li>
<li class=""><strong>Node.js v21</strong> — Not supported (EOL)</li>
<li class=""><strong>Node.js v22</strong> — Supported (Active LTS)</li>
<li class=""><strong>Node.js v23</strong> — Not supported (EOL)</li>
<li class=""><strong>Node.js v24+</strong> — Supported</li>
</ul>

<h3 class="anchor anchorTargetStickyNavbar_tleR" id="other-breaking-changes">Other Breaking Changes<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#other-breaking-changes" title="Direct link to Other Breaking Changes">​</a></h3>
<h4 class="anchor anchorTargetStickyNavbar_tleR" id="general">General<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#general" title="Direct link to General">​</a></h4>
<ul>
<li class=""><code>Pressable</code> no longer unmounts event listeners in hidden <code>Activity</code>.</li>
<li class="">Removed deprecated C++ type aliases for <code>ShadowNode::Shared</code>, <code>ShadowNode::Weak</code>, <code>ShadowNode::Unshared</code>, <code>ShadowNode::ListOfWeak</code>, <code>ShadowNode::ListOfShared</code>, <code>SharedImageManager</code> and <code>ContextContainer::Shared</code> — Those were not in use and consumer libraries should use the type directly.</li>
</ul>
<h4 class="anchor anchorTargetStickyNavbar_tleR" id="android">Android<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#android" title="Direct link to Android">​</a></h4>
<ul>
<li class="">We re-added <code>receiveTouches</code> to <code>RCTEventEmitter</code> with default no-op. This is a fix to reduce breaking changes for libraries that haven't migrated away from this method yet.</li>
<li class=""><code>ReactTextUpdate</code> is now internal and should not be accessed publicly directly.</li>
<li class="">Multiple classes deprecated or removed as legacy architecture cleanup:<!-- -->
<ul>
<li class=""><code>ReactZIndexedViewGroup</code> is now deprecated.</li>
<li class=""><code>UIManagerHelper</code> is now deprecated.</li>
<li class=""><code>CatalystInstanceImpl</code> has been removed (it was deprecated).</li>
<li class=""><code>NativeViewHierarchyManager</code> has been fully stubbed out.</li>
</ul>
</li>
</ul>
<h4 class="anchor anchorTargetStickyNavbar_tleR" id="ios">iOS<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#ios" title="Direct link to iOS">​</a></h4>
<ul>
<li class="">The <code>RCTHostRuntimeDelegate</code> is now deprecated and merged into <code>RCTHostDelegate</code>.</li>
<li class="">Fixed duplicate symbol error when using <code>React.XCFramework</code> (via <code>fmt</code> bump to 12.1.0).</li>
</ul>
<h2 class="anchor anchorTargetStickyNavbar_tleR" id="other-changes">Other Changes<a class="hash-link" href="https://reactnative.dev/blog/2026/04/07/react-native-0.85#other-changes" title="Direct link to Other Changes">​</a></h2>
<ul>
<li class=""><strong>Metro</strong> bumped to <code>^0.84.0</code>.</li>
<li class=""><strong>React</strong> updated to consume Hermes <code>250829098.0.10</code>.</li>
<li class=""><strong>Yoga</strong>: <code>YogaNode</code> migrated to Kotlin on Android.</li>

<li class=""><strong>Android Build</strong>: Allow specifying dev server IP via <code>reactNativeDevServerIp</code> Gradle property.</li>
<li class=""><strong>iOS Build</strong>: Added support for clang virtual file system in <code>React.XCFramework</code>.</li>
</ul>
